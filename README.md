# SafePay AI

- Fraud risk scoring
- Voice alerts
- Multilingual warnings
- Real-time phishing analysis

## Tech Stack

- Flask
- HTML
- CSS
- JavaScript
- Scikit-learn
- Logistic Regression
- TF-IDF
